# First Python CI Demo
Browser-based GitHub Actions practical.

## Files
- `result_logic.py`: simple pass/fail rule
- `test_result_logic.py`: unit tests
- `.github/workflows/ci.yml`: workflow equivalent is stored at the repository root under `.github/workflows/practical-1-ci.yml`

Commit changes to `main` to trigger the workflow. Use Actions → Practical 1 - First Python CI to inspect runs.
